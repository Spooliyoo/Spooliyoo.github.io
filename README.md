# Spooliyoo

Know how many grams are left on every 3D-printer spool, and what every print really costs.

Spooliyoo is a free, open-source **offline-first web app**. It installs on your phone or computer like an app, and **all your data stays on your device**: no account, no server, no tracking.

**Live app:** `https://<your-user>.github.io/<repo>/` _(set once the repository is public)_

## Features

- **Spools**: give each spool any unique ID (box code, your own label, later an NFC/QR value). Track brand, material, colour, price, net weight and empty-spool weight.
- **Remaining filament**: calculated from everything you log, never typed in by hand. Put a spool on a scale to correct it at any time.
- **Print log**: model weight + purge waste + extra filament, deducted from one or more spools. Multi-part models are logged once, with each part's own time and spools. Failed prints count as waste. Add reference photos.
- **Recently deleted**: deleted prints can be restored for 30 days.
- **Price calculator**: filament, electricity, printer wear, labour, a failure buffer and markup, shown live as you type. Each print keeps its own rates, so changing a setting never rewrites past prices.
- **Dashboard and history**: stock value, low-stock spools, this month's usage, cost, revenue and profit. Search and filter every print.
- **Backups**: export everything (photos included) to one JSON file and restore it on any device; export prints to CSV.
- **Works offline** once it has loaded, and tells you when an update is ready.

## Install the app

| Device                                     | How                                                                                          |
| ------------------------------------------ | -------------------------------------------------------------------------------------------- |
| Android / Chrome / Edge / Samsung Internet | Open the site and tap **Install app** (in Settings, or the browser menu).                    |
| iPhone / iPad                              | Open in **Safari** → **Share** → **Add to Home Screen**.                                     |
| Windows / macOS / Linux / ChromeOS         | In Chrome or Edge, click the install icon in the address bar or **Install app** in Settings. |
| Firefox desktop                            | Runs as a normal website (Firefox can't install web apps).                                   |

> **Your data lives in this browser on this device.** Clearing site data or uninstalling the browser deletes it. Export a backup from **Settings → Backup and export** regularly. The app asks for persistent storage so the browser won't clear it when space is low.

## Self-hosting

The app is plain static files, so any static host works (Nginx, Caddy, Apache, Netlify, Cloudflare Pages, a NAS…). It must be served over **HTTPS** (or `localhost`) for offline mode and install to work.

**From a release:** download `filament-tracker-vX.Y.Z.zip` from [Releases](../../releases), unzip it, and serve the folder at the root of a domain or subdomain.

**From source** (Node 20+):

```bash
npm ci
npm run build                                   # outputs out/
NEXT_PUBLIC_BASE_PATH=/tools/filament npm run build   # if serving under a sub-path
npm start                                       # preview out/ at http://localhost:4173
```

Serve `.wasm` files as `application/wasm` (most servers already do).

### Deploying your own copy to GitHub Pages

1. Fork or push this repo to GitHub.
2. **Settings → Pages → Source: GitHub Actions.**
3. Push to `main`. The workflow lints, tests, builds with the right base path (`/<repo>`) and publishes.
4. Using a custom domain or a `<user>.github.io` repo? Add a repository variable `BASE_PATH` = `/`.

## Development

```bash
npm ci
npm run dev          # http://localhost:3000 (service worker disabled in dev)
npm test             # unit tests (Vitest) — calculations and the database layer on real PGlite
npm run build && npm run test:e2e   # end-to-end tests (Playwright) against the production build
npm run lint && npm run typecheck
```

### Stack

Next.js (App Router, static export) · TypeScript (strict) · Tailwind CSS with shadcn/ui-style components · [PGlite](https://pglite.dev) (Postgres in the browser, persisted to IndexedDB) · Drizzle ORM · React Hook Form + Zod · TanStack Query · Serwist (service worker) · Vitest + Playwright.

### Project layout

```
src/app/            screens (/, /spools, /spools/view?id=, /prints/new, /prints, /settings …)
src/components/     UI, forms, PWA helpers
src/lib/calc/       pure formulas (price, remaining grams) — fully unit-tested
src/lib/db/         schema, migrations, queries, backup/CSV
drizzle/            SQL migrations generated by drizzle-kit
```

### Changing the database

1. Edit `src/lib/db/schema.ts`.
2. `npm run db:generate` — creates a new SQL file in `drizzle/` and bundles it into `src/lib/db/migrations.generated.ts`.
3. Migrations run automatically in each user's browser on the next launch. If the change affects backups, bump `BACKUP_SCHEMA_VERSION` in `src/lib/db/backup.ts` and add an upgrade step.

Remaining grams are never stored. They are always derived from usage lines and weight corrections, so edits and deletes stay consistent.
